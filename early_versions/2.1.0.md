Adds a guest mode on the `guest-mode` branch so users can use Stickee without a regular sign-up/sign-in by creating a guest account with only a name and password. Guest accounts are backed by Supabase auth (deterministic identity derived from the normalized guest name) so data persists across sign-out/sign-in, and guest names are unique (e.g. `joe` cannot be reused; `joe1` is suggested/allowed as a different name). In the profile, guests keep an editable name and profile picture/avatar while their email displays `YOU HAVE A GUEST ACCOUNT` (read-only). by @slammers001
